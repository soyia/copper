# Security policy

This is the 0.4.0-rc.11 source prerelease. There is no stable/LTS service commitment, certified device matrix, guaranteed response time or commercial SLA in this release. Historical component SECURITY/SUPPORT documents retain their dates; this root file defines the public source reporting entry.

Report suspected vulnerabilities privately at https://github.com/soyia/copper/security/advisories/new. Do not include customer data, secrets, private keys, backups, exploit instructions or production logs in public Issues. Provide the public source tag/commit, affected component, impact and synthetic reproduction.

If private reporting is unavailable, open an Issue with only the title Security contact requested and no technical details; wait for a private channel. Do not post credentials to try to make the report easier to reproduce.

No new container or installer security certification is claimed by the source publication. The earlier internal runtime scan and the known third-party/vendor material limitations are described in THIRD_PARTY.md and RELEASE_NOTES.md.
