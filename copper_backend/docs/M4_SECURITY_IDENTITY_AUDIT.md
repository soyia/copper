# M4-02 身份、权限、数据范围与高风险审计

## 完成范围

- 登录失败计数、15 分钟锁定和失败审计与登录事务一起提交，异常返回不再回滚安全状态。
- 首次管理员仍使用一次性凭据文件；首次修改密码后销毁文件并撤销全部临时会话。
- 会话由“物理删除”改为“撤销留痕”，记录撤销时间、原因和操作者。
- 默认会话有效期 12 小时，同一账号最多 5 个有效会话；第 6 次登录撤销最早使用的会话。
- 用户可查看和撤销自己的登录设备；管理员可填写原因后撤销其他用户的全部会话。
- 角色、权限、数据范围、账号状态或密码变化后，旧会话立即失效。
- 后端继续按接口强制权限，并增加主数据路径、请求体关联主键和业务单据来源的数据范围校验。
- 登录、退出、会话拒绝、权限拒绝、权限/数据范围变化、完整业务导出及所有业务写请求进入统一安全审计。
- 安全审计列表仅返回业务需要的安全字段，IP 脱敏，不返回密码、令牌、Cookie、一次性凭据和原始 User-Agent。

## 关键策略

| 项目 | 默认值 | 可配置项 |
| --- | --- | --- |
| 会话有效期 | 12 小时 | `COPPER_SESSION_HOURS`，范围 1–168 |
| 同账号有效会话 | 5 个 | `COPPER_MAX_ACTIVE_SESSIONS`，范围 1–20 |
| 撤销/过期会话保留 | 90 天 | 当前为产品安全基线 |
| MySQL 业务会话时区 | `+08:00` | `COPPER_DB_TIME_ZONE_OFFSET` |
| 安全审计查询上限 | 200 条/次 | 接口硬上限 |

保留多个设备是面向小微经营者的必要便利；通过“最多 5 个 + 可见设备 + 可撤销 + 超限撤销最旧会话”控制风险。单会话强制互踢会明显增加手机、办公室电脑和仓库终端之间的使用成本。

## 审计口径

安全审计与库存流水、应收应付、收付款、核销和单据审核流水分开保存，不能代替业务账簿。每个安全事件包含：

- 唯一事件号、结果（成功/已拒绝/失败）和失败编码；
- 操作用户、会话、目标类型、目标主键或业务键；
- 服务端生成的追踪号、请求方法、请求路径、脱敏 IP 和 User-Agent 哈希；
- 业务说明、必要的变更前后快照和微秒级发生时间。

变更快照会递归遮蔽字段名中包含 `password`、`token`、`secret`、`cookie` 或 `credential` 的内容。未知账号登录只保存规范化账号的 SHA-256，不保存用户输入原文。

## 接口

- `GET /auth/sessions`：查看当前用户的有效设备。
- `POST /auth/sessions/{id}/revoke`：撤销本人指定设备。
- `POST /system/users/{id}/sessions/revoke`：管理员填写原因后撤销用户全部设备。
- `GET /system/security-audit`：按动作、结果、操作人和时间查询，要求 `security.audit.view`。

## 数据库迁移

`V5__security_session_audit.sql` 只追加字段和索引：

- 会话增加撤销时间、原因和操作者；
- 用户增加最后改密时间；
- 安全审计增加事件号、结果、失败码、会话、追踪号、请求来源、标识哈希、业务键和业务发生时间；
- 已有审计记录以原主键确定性回填事件号和追踪号，不覆盖原审计内容。

## 验收结果

- Java 17 本地：`mvn -q test` 全部通过。
- 前端：`pnpm build` 通过。
- `local-database` MySQL 8.4.10 空库：V1–V5 启动成功，readiness 为 `UP`。
- V1–V4 已有库升级：V5 成功，旧审计记录的事件号、追踪号和发生时间全部回填。
- 5 次错误密码：失败计数为 5，生成 5 条已拒绝审计；重置后可正常登录。
- 首次改密：一次性凭据文件被销毁，临时会话以 `PASSWORD_CHANGED` 撤销。
- 6 次重复登录：有效会话保持 5 个，最旧会话以 `CONCURRENT_LIMIT` 撤销。
- 数据范围：受限用户列表只看到授权往来单位；越权详情和越权请求体均返回 403，越权联系人未写入数据库。
- 权限：缺少商品权限访问返回 403；权限和数据范围拒绝均产生 `ACCESS_DENIED` 审计。
- 真实浏览器：登录设备加载、撤销其他设备、成功反馈和当前会话保持通过；安全审计 52 条记录加载成功，无控制台错误、无横向溢出，时间按中国时区显示。

`local-database` 当前系统 Java 25 超出项目 Mockito/Byte Buddy 的支持范围，远端旧测试也会因运行时插桩失败；远端使用 Java 17 字节码构建并完成真实 MySQL/HTTP 验收，自动化单元测试以项目基线 Java 17 的通过结果为准。
