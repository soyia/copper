# Public source support scope

Report ordinary defects through https://github.com/soyia/copper/issues using the exact tag/commit and synthetic reproduction. Security reports use SECURITY.md. This source prerelease is aimed at developers/operators who can build and configure their own isolated environment. It is not a zero-support installer, stable release, contracted managed service or customer handover.

The recorded runtime acceptance baseline is Ubuntu Server 24.04 LTS amd64, MySQL 8.4 and Java 17. Build instructions use public package dependencies. Real browser/mobile device acceptance, external legal/accounting review, customer nondeveloper installation, key witness and signatures remain owner-deferred; none is claimed passed. Other operating systems, ARM64, NAS/LAN/VM/device certifications and direct upgrades are not promoted by this source publication.

Customer accounts, data, servers and recovery keys remain under their control. No maintenance expiry or remote licensing heartbeat may lock their existing core business/data. There is no signed SLA, 24/7 promise or fixed RTO in this source edition. Commercial service terms, if any, require a separate agreement.
