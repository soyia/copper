## 4. 失败关闭验证和演练偏差

本次真实触发三项保护：非法的“域名带端口”配置被备份门禁拒绝；`offline` 模式的可变镜像标签被拒绝；临时 Compose 覆盖无法被备份重启链继承，80/443 冲突时没有覆盖现有 M5 入口。最终改为产品内置 `external-proxy` 模式和精确本地镜像 ID 后，备份停写、服务恢复和 `BACKUP_RECOVERED` 留痕通过。

首次改密已经按产品流程通过。随后自动化脚本只把新密码保留在内存，发生失败后无法继续登录；为完成一次性测试站，使用源码同参数 PBKDF2 直接重置了测试管理员密码。该操作仅用于随后全部销毁的虚构站点，不是产品支持的客户密码恢复流程，也不能作为正式运维证据。
