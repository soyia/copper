# Copper 中国境内试运营条款

> 版本：CN-TRIAL-20260713
> 状态：M0 中国境内试运营确认版
> 适用范围：中国大陆境内的小微企业、个体工商户及其他经营主体购买 Copper 部署、维护、迁移和技术服务
> 不适用：境外客户、跨境数据、消费者个人生活消费、金融/医疗等高度监管行业、正式公开源码再发行授权

本条款用于 Copper 尚未配备专职会计和律师阶段的保守试运营。它依据当前有效的中国官方法律和税务口径形成，可以作为订单、交付和内部执行基线，但不构成国家机关、注册会计师或执业律师出具的专业意见。

## 1. 使用前必须填写的订单信息

每笔收费业务必须先形成订单或服务确认单，至少填写：

- 服务提供方名称、统一社会信用代码/身份证明、联系方式和收款账户。
- 客户名称、统一社会信用代码/身份证明、联系人和联系方式。
- 具体服务：客户云部署、本地/NAS部署、数据迁移、安心维护、代运维、定制或接口。
- 生产环境数量、标准环境/非标准环境、交付内容和明确不包含事项。
- 含税总价、付款时间、发票需求和第三方费用。
- 交付日期、验收方式、临时权限、备份位置和恢复责任。

没有依法可用于经营收款的服务主体时，只能开展免费内测，不得以个人临时收款方式对外承诺发票和持续商业服务。

## 2. 产品与价格

1. Copper 核心软件费用为 ¥0，不按用户、仓库、商品、单据、站点或人工存储配额收取功能费。
2. 客户支付的是部署、迁移、维护、代运维、定制和其他明确约定的人工技术服务费。
3. 当前中国境内目标含税价以 `PRICING_AND_SERVICE_CATALOG.md` 为准。
4. 云服务器、域名、对象存储、短信、OCR、地图、电子发票、银行、物流和打印等第三方费用不包含在 Copper 服务费中，原则上由客户直接购买。
5. 停止购买维护或代运维，不影响客户现有 Copper 实例继续运行，也不影响客户导出、备份和恢复自身数据。

## 3. 税务和发票

### 3.1 统一口径

- 对外标价和订单总价均为人民币含税价，除客户新增服务外，不能在付款时再追加税点。
- Copper 软件本身免费；收费项目按实际发生的部署、维护、迁移、技术支持或定制服务选择税收分类编码。
- 发票类型、税率和税收分类以服务提供方开票当期的纳税人身份、电子税务局可选项目和实际交易性质为准。
- 客户要求增值税专用发票的，必须在下单前确认服务提供方具备相应开票条件；不能先承诺后补资格。

### 3.2 2026年内部计算基线

- 服务提供方为增值税小规模纳税人时，2026年至2027年多数原适用3%征收率的应税交易按现行政策减按1%征收；实际免税、开票和申报按当期规则执行。
- 服务提供方为一般纳税人时，信息技术等现代服务通常适用6%增值税税率。
- 无论内部按1%、6%或依法免税处理，客户订单的含税总价不因此上浮；税额从含税总价中依法拆分。
- 在服务主体首次收费和首次开票前，应登录电子税务局确认纳税人身份和可开票项目，并将截图/结果留作内部证据；这不要求必须聘请专职会计。

## 4. 交付与验收

1. Copper 仅对订单列明的服务和正式兼容环境负责。
2. 标准部署交付至少包括：安装结果、当前版本、访问地址、管理员交接、数据/附件/备份位置、一次备份及恢复验证结果和已知风险。
3. 客户应在收到交付材料后 5 个工作日内完成验收或一次性提出具体问题；Copper 修复属于约定范围的问题后重新提交验收。
4. 未完成真实备份恢复验证的部署，不得标记为“完整交付”。
5. 客户在验收后自行修改系统、数据库、网络或容器配置产生的问题，不属于原部署缺陷，但 Copper 可以按服务目录提供有偿协助。

## 5. 取消、重做和退款

1. 服务尚未开始，客户可以取消并退回未发生的服务费。
2. 服务已开始，按已完成成果、实际工时和已发生的不可退第三方费用结算。
3. 客户环境符合正式兼容清单，但因 Copper 标准部署资产缺陷无法完成时，Copper应选择修复、免费重做或退回未交付部分费用。
4. 因客户取消权限、未提供必要账号、第三方欠费、网络/硬件故障或客户擅自变更环境导致无法交付，不视为 Copper 产品缺陷。
5. 数据迁移和定制服务应先验样本再批量执行；客户确认后的原始数据错误不由 Copper 承担业务真实性责任。

## 6. 数据、个人信息和保密

1. 客户是其业务数据和个人信息处理目的、方式的决定方；客户负责确保录入联系人、员工、银行账户等信息具有合法处理基础。
2. 本地或客户云部署下，Copper默认不持续取得客户业务数据。只有在客户明确授权远程部署、迁移、排障或代运维时，Copper才作为受托处理方在必要范围内接触数据。
3. 每次受托处理应记录目的、期限、方式、数据种类、权限、保护措施和操作人；不得超出故障或服务所需范围查看、复制和导出数据。
4. 未经客户书面同意，不得转委托，不得将客户数据传到境外，不得用于训练模型、产品画像、广告或与当前服务无关的分析。
5. 服务结束后，Copper应撤销临时权限，并按客户要求返还或删除临时复制的数据，不得私自保留。
6. 发现数据泄露、丢失、篡改或越权访问时，应立即保护现场、停止扩大影响并通知客户，不迟于发现后24小时提供已知情况和初步措施。
7. 双方对在服务中获知的账号、密钥、价格、客户名单、交易和经营信息承担保密义务。

## 7. 服务器、备份和安全责任

- 客户持有服务器/云账号、域名、数据库管理员凭据、备份和备份加密密钥。
- Copper只使用完成服务所需的最小权限；删除数据、覆盖恢复、开放公网端口和数据库升级必须单独确认。
- 自助部署由客户承担安全、备份、恢复和升级责任。
- 标准部署由 Copper 完成订单约定的一次性交付，交接后的日常运维由客户承担。
- 代运维按合同约定执行，仍不改变客户对基础设施和业务数据的最终控制权。
- 详细责任以 `DEPLOYMENT_RESPONSIBILITY_MATRIX.md` 为准。

## 8. 客户源码使用授权

在 Copper 正式公开开源前，对已经完成正式部署和源码交付的客户，采用以下中国境内非独占源码使用规则：

1. 授权范围：客户可永久为自身内部经营运行、复制备份、修改、构建和部署与其运行版本对应的 Copper 源码。
2. 委托维护：客户可委托承担书面保密义务的第三方服务商维护其自身实例，但应保证该服务商不将源码用于其他客户或产品。
3. 禁止范围：未经单独商业授权，不得向无关第三方公开源码/安装包，不得改名销售、出租、提供公共SaaS、OEM分发或使用 Copper 商标宣称官方版本。
4. 客户修改：客户应保留原始版本、修改记录和数据库迁移；客户自行修改导致的问题不自动属于 Copper 免费维护责任。
5. 第三方组件：继续适用各自原许可证，本授权不能扩大第三方组件权利。
6. 正式开源后：客户可对公开版本选择适用公开许可证；未公开版本和 Copper 商标仍按原授权处理。

本授权为非专有许可，不转让 Copper 软件著作权。需要闭源OEM、公共SaaS或再分发时另签商业授权。

- Copper 自主开发代码、文档和正式发布资产的著作权归合法权利人所有。
- 客户始终拥有其业务数据；数据所有权不因使用 Copper 或接受服务而转移。

## 10. 责任限制

1. 双方应先通过备份、恢复、停止危险写入和日志审计控制损失扩大。
2. Copper对自身故意或重大过失、造成对方人身损害以及法律明确不得限制的责任，不适用免责或责任上限。
3. 除前款外，Copper对单项收费服务承担的累计直接损失责任原则上不超过客户就该单项服务实际支付的服务费；该限制必须在订单中加粗提示并允许客户提出协商。
4. Copper不对客户原始数据错误、客户擅自改库、未保留有效备份、第三方服务中断以及不可归责于 Copper 的硬件/网络故障承担结果保证责任。
5. “软件免费”不等于无视产品缺陷；Copper发现影响库存、应收应付、资金、安全或数据恢复的严重缺陷时，应发布风险提示和修复方案。

## 11. 重要格式条款提示

下列内容必须在下单或签署时用加粗、单独勾选或其他显著方式提示客户，并按客户要求解释：

- 服务范围和明确不包含事项。
- 验收期限和问题反馈方式。
- 退款、重做和第三方费用规则。
- 客户数据、备份和安全责任。
- 源码禁止转售、公共SaaS、OEM和商标使用规则。
- 责任限制和争议解决条款。

不得通过格式条款排除客户主要权利、免除 Copper 故意或重大过失责任，或不合理地加重客户责任。

## 12. 适用法律与争议解决

- 本条款和订单适用中华人民共和国大陆地区法律。
- 发生争议时先协商和核对订单、交付记录、日志、备份及审计证据。
- 协商不成的，任一方可向被告住所地有管辖权的人民法院起诉。
- 单独协商形成的订单条款与本标准条款不一致时，以双方单独协商的书面条款为准。

## 14. 版本与复核触发条件

本版本可以支持中国境内低风险试运营。出现以下任一情况必须暂停套用并专项复核：

- 首次正式公开 GitHub/Gitee 源码或接受外部贡献。
- 提供公共SaaS、多租户、跨境数据或境外客户服务。
- 接入银行、税控、医疗、未成年人或大规模敏感个人信息。
- 单客户合同金额、赔偿风险或定制范围显著提高。
- 服务主体纳税人身份、主营业务、开票项目或税务政策发生变化。
- 发生真实数据泄露、重大库存/资金差错或知识产权争议。
