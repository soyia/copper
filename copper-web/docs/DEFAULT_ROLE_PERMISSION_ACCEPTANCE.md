## 2. 默认岗位矩阵

| 岗位 | 默认工作可用 | 成本与毛利边界 | 凭证、税票、银行、反结账边界 | 单据范围 |
| --- | --- | --- | --- | --- |
| 老板 | 经营工作台、采购、销售、收付款 | 可看库存成本 | 可改暂存凭证、维护银行账户、规范反结账 | 全部 |
| 财务 | 收付款核销、凭证审核记账、税票、银行对账、结账 | 可看库存成本 | 可作废符合条件的税票、维护银行账户；默认不得反结账 | 全部 |
| 库管 | 入库、出库、调拨、盘点 | 不得看采购价、库存成本、销售毛利 | 不得改凭证、作废税票、维护银行账户、反结账 | 全部 |
| 销售 | 客户跟进、销售订单、出库、本人业务应收 | 不得看采购价、库存成本、销售毛利 | 不得改凭证、作废税票、维护银行账户、反结账 | 本人 |
| 采购 | 采购订单、采购入库、采购退货、采购询价成本 | 可看采购价，不得看库存计价金额和销售毛利 | 不得改凭证、作废税票、维护银行账户、反结账 | 本人 |

多人兼岗时，系统按角色权限并集授权。不能依赖“主要岗位权限较少”抵消另一岗位已经授予的敏感权限。

## 4. 高风险权限拆分

| 业务动作 | 权限码 | 默认岗位 |
| --- | --- | --- |
| 确认发票 | `invoice.confirm` | 老板、财务及管理员 |
| 作废发票 | `invoice.void` | 老板、财务及管理员 |
| 银行流水匹配与对账 | `financial.bank.manage` | 老板、财务及管理员 |
| 企业银行账户维护 | `financial.bank.account.manage` | 老板、财务及管理员 |
| 正式期末结账 | `financial.close.manage` | 老板、财务及管理员 |
| 规范反结账 | `financial.close.reopen` | 老板及管理员 |

权限拆分后，前端按钮可见性和后端接口拦截使用同一权限码。是否具备权限仍不等于业务条件一定满足；税票状态、会计期间、复核原因和审计证据继续由业务服务校验。

## 5. 后续回归要求

1. 每次修改预置角色、权限迁移或高风险接口映射后，先运行前后端自动化测试。
2. 再打开“默认岗位验收”，确认五个岗位实时授权全部通过。
3. 至少用真实会话复核本次涉及岗位的一个正向接口和所有相关高风险拒绝接口。
4. 验收账号只能使用脱敏测试数据，完成后必须清理账号、会话、Cookie 和本次拥有的浏览器/服务进程。
5. 任一岗位出现失败、越权接口不是 `403`、或本职接口不是 `200` 时，不得宣称权限验收完成。
