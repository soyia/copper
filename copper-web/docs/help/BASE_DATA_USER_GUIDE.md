# 基础资料使用手册

> 适用范围：基础资料中的计量单位、仓库资料、分类与规格、计量与包装、商品资料和商品批量导入。  
> 建议使用角色：老板、系统管理员、商品资料维护人员。采购、销售和仓库人员以查询、核对为主。

基础资料决定采购、入库、库存、销售和出库时“选什么商品、用什么单位、进哪个仓库”。建议在正式开单前集中维护，日常发现缺项时再补充。已经发生业务的资料不要为了改名或换单位而重复新建，也不要用停用来掩盖错误业务。

## 一、开始前先理解三个原则

1. **一物一档。** 同一产品系列下，能够影响询价、库存区分或客户交付的材质、牌号、状态、标准、外径、壁厚、长度等，应体现在商品规格中，不能只写在备注里。
2. **库存单位保持稳定。** 商品的主库存单位用于记录库存结存。采购或销售可以使用受控包装单位，但必须通过明确的换算关系落到主库存单位。
3. **数量精度与金额分开。** 库存、业务数量及包装重量最多保留六位小数，页面省略末尾的零；例如 `0.001 t = 1 kg`。金额按两位小数显示，不能把金额的两位精度套到数量或换算系数上。
4. **历史业务保留原口径。** 后续修改分类、规格、包装或仓库资料，不应改写已经确认的订单、出入库单和库存批次。确需纠错时，应回到原业务单据按允许的变更、撤销或冲正流程处理。

## 二、推荐初始化顺序

首次使用时，建议按下面顺序维护：

1. 计量单位：建立重量、长度、计数和包装等单位。
2. 仓库资料：建立实际存放货物的仓库和收货地址。
3. 分类与规格：建立产品分类、产品系列和各系列的建档字段。
4. 计量与包装：建立常用包装模板，并应用到产品系列。
5. 商品资料：按实际经营规格建立可以采购、销售和库存核算的商品。
6. 批量导入（高级）：仅在已有大量规范数据时使用；先少量试导并修正问题，再导入全部数据。

不要先批量建商品、再临时补单位和规格。这样容易产生重复商品、错误换算和无法对账的库存口径。

## 三、维护计量单位

入口：**基础资料 → 计量单位**

### 3.1 先建计量分类

计量分类用于约束同类单位。可按实际经营需要建立“重量”“长度”“数量”“包装”等分类。

操作方法：

1. 在“计量分类”区域点击“新增分类”。
2. 填写名称和说明，状态保持“启用”。
3. 保存后，再在下方“计量单位”区域新增具体单位。

### 3.2 再建具体单位

1. 点击“新增单位”。
2. 选择所属分类。
3. 填写单位名称，例如千克、吨、米、支、盘、卷、箱。
4. 按需要填写缩写和受控别名。
5. 选择单位类型：度量单位用于重量、长度等连续计量；计数单位用于支、件等数量计量；包装单位用于盘、卷、箱等包装层级。
6. 保存并确认状态为“启用”。

名称、缩写和受控别名应保持唯一。导入数据只会按这些受控值识别单位，不会因为出现一个陌生写法就自动创建新单位。

### 3.3 维护建议

- 同一含义只保留一个标准单位，例如不要同时建立“公斤”和“千克”两个独立单位；可将“公斤”作为“千克”的受控别名。
- “吨”和“千克”虽然都属于重量单位，但商品主库存单位只能选一个。日常以千克管理库存时，建议主库存单位使用千克。
- “盘”“卷”“箱”通常是包装单位，不能只凭名称推断其中有多少千克、米或支；换算关系应在“计量与包装”中维护。
- 已经被商品或历史业务使用的单位，不要改成另一种含义。确实不再使用时，将其设为“不可用”，历史数据仍应保留原单位。

## 四、维护仓库资料

入口：**基础资料 → 仓库资料**

### 4.1 新增仓库

1. 点击“新增仓库”。
2. 填写仓库名称。名称应能让开单人员直接识别实际货位或管理边界，例如“即墨成品仓”“城阳临时仓”。
3. 填写位置。
4. 填写收货地址；有多个地址时一行填写一个。
5. 状态选择“启用”并保存。

只有具有仓库维护权限的用户才能看到新增和编辑操作。

### 4.2 仓库划分原则

- 仓库代表需要独立核对结存的实际存放范围，不要为了方便筛选而把客户、供应商或业务员建成仓库。
- 供应商直接送货给客户、货物不进入本企业仓库时，应使用直运购销，不要建立“虚拟仓库”制造假入库和假出库。
- 同一地点仅因货架、区域不同，是否拆成多个仓库应以是否需要独立盘点、独立责任和独立结存为判断标准。
- 仓库停用后，不应再用于新采购、入库、销售或出库，但历史库存与单据必须继续可查。停用前应先确认没有待处理业务和未清库存。

## 五、维护分类与规格

入口：**基础资料 → 商品主数据 → 分类与规格**

### 5.1 产品分类

产品分类用于查找和汇总商品，可以按经营目录分层维护。系统应覆盖本企业实际经营的铜管、铜排、电解铜、铜焊条、保温管、管件等商品，不要把所有商品都放进“其他”。

1. 点击“新增分类”建立分类。
2. 点击左侧分类，右侧会显示该分类下的产品系列。
3. 需要调整名称或状态时，点击该行“编辑”。

分类只用于组织和筛选，不负责包装换算，也不直接决定商品规格。

### 5.2 产品系列

产品系列是一组共享规格结构的商品，例如同一类紫铜直管或铜排。

1. 选中目标分类。
2. 点击“新增本级系列”。
3. 填写系列编码、名称和必要说明。
4. 根据实际需要选择包装单位分类、计价单位分类。
5. 保存后，在该系列行点击“规格”维护建档字段。

### 5.3 建档字段和商品区分

建档字段用于记录该系列真正需要的规格信息。不同产品形态应选择不同字段：

- 管材常用：材质或牌号、软硬状态、执行标准、外径、壁厚、长度。
- 铜排常用：牌号、状态、宽度、厚度、长度。
- 电解铜常用：牌号、执行标准、单重或包装规格。
- 管件和分歧管常用：接口规格、分支规格、结构形式。
- 保温管常用：铜管规格、保温形式、保温厚度。
- 铜焊条常用：牌号、直径、长度、包装规格。

操作方法：

1. 在产品系列行点击“规格”。
2. 在“建档字段”中新增或选择字段。
3. 对会影响商品唯一性的字段勾选“用于区分商品”。系统会将其作为必填项并参与同系列重复检查。
4. 常用组合可在“规格预设”中维护，商品建档时可快速带入；预设不是新的商品。
5. 保存后，用一条典型商品试建，确认字段顺序、单位和重复检查符合实际。

不要把每一个具体规格都建成产品系列，也不要把不同形态商品强行套用一组仅适用于圆管的字段。

## 六、维护计量与包装

入口：**基础资料 → 商品主数据 → 计量与包装**

计量与包装包含“包装模板”“系列应用”和“商品规则”三部分。推荐做法是：模板定义通用换算，系列统一应用，只有确实不同的商品才设置特例。

### 6.1 建立包装模板

1. 打开“包装模板”页签，点击“新增模板”。
2. 填写模板编码、名称和适用说明。
3. 确认主库存单位。
4. 按真实包装层级维护换算关系，例如箱到盘、盘到米，或卷到千克。
5. 检查精度和换算来源，发布模板。

固定换算只适合每个包装数量稳定的情况。如果每盘重量或长度不固定，应使用系统支持的实际换算或业务录入方式，不能填一个大概数长期使用。

### 6.2 应用到产品系列

1. 打开“系列应用”页签。
2. 找到目标产品系列。
3. 点击“应用模板”或“变更模板”。
4. 核对主库存单位、适用范围和风险提示后保存。

模板变更只应影响后续业务的有效规则。历史订单、出入库单和库存批次应继续保留当时的包装快照。

### 6.3 商品特例

1. 打开“商品规则”页签。
2. 按 SKU、名称或规格找到商品。
3. 只有该商品确实不同于系列通用规则时，才点击“设置特例”。
4. 填写差异并保存，随后检查“规则来源”“有效包装”和“有效版本”。

如果同一系列出现大量商品特例，通常说明系列划分或模板设计不合理，应先调整通用规则，不要持续堆叠特例。

## 七、建立商品资料

入口：**基础资料 → 商品主数据 → 商品资料**

商品资料是采购、销售和库存使用的实际 SKU。建档前应准备厂家资料、牌号或材质、状态、执行标准、关键尺寸、主库存单位、常用采购销售单位和供应商信息。

### 7.1 新增商品

1. 点击新增商品。
2. 在“商品与规格”步骤选择产品系列。
3. 可选择规格预设，也可以直接填写经营规格。
4. 逐项填写必填字段；带“区分”标记的字段用于避免重复商品。
5. 看到重复提示时，先检查已有商品，不要仅通过改名称或加空格绕过重复检查。
6. 进入“单位与供货”步骤，确认主库存单位。
7. 按实际需要维护包装、默认价格和供应商供货资料。
8. 保存后，在商品列表检查 SKU、名称、规格、单位、资料完整性和经营状态。

### 7.2 命名和规格要求

- 商品名称用于快速识别，关键规格仍应填写在结构化字段中。
- 厂家原始编码、条码可用于查找和识别，但不能代替本系统商品身份。
- 同一商品不要因供应商不同重复建档；不同供应商的编码、价格或包装应维护为该商品的供货资料。
- 商品确实存在影响库存或交付的规格差异时，应建立不同 SKU。
- 主库存单位一旦形成库存事实，不应随意变更。需要改变核算口径时，应先评估现有库存、未完成单据和历史追溯影响。

### 7.3 编辑、复制和停用

- 编辑：用于补充或更正尚未改变商品身份含义的资料。
- 复制：适合建立同系列、规格相近的新商品；保存前必须核对所有区分字段、单位和供应商资料。
- 停用：用于禁止后续新业务继续选择该商品，不删除历史订单、库存和流水。

如果商品已经发生业务，不能通过改成另一种规格来节省一个 SKU。应保留原商品，按实际情况新建正确商品，并对错误业务走规范纠错流程。

## 八、商品批量导入（高级）

入口：**基础资料 → 商品主数据 → 批量导入（高级）**

批量导入适合已经整理好大量规范商品数据的场景，不是首次理解商品模型的捷径。只有具有相应高级权限的用户才能看到入口。

推荐步骤：

1. 先完成计量单位、分类、产品系列、建档字段和必要包装模板。
2. 按系统模板整理数据，不擅自改变列名和数据格式。
3. 先导入少量代表性商品，至少覆盖管材、铜排、电解铜、管件等不同规格形态。
4. 查看校验结果，修正未知单位、缺少必填规格、重复商品和无效分类等问题。
5. 抽查导入后的商品详情和包装规则。
6. 小批验证正确后，再导入剩余数据。

不要让导入程序静默创建未知单位、随意换算数量，或仅凭商品名称判断为同一商品。导入失败时应修正源数据后重新校验，不要在系统中批量修改已经正确的资料去迎合错误文件。

## 九、日常检查清单

每次新增或调整基础资料后，至少检查：

- 商品能否按分类、系列、SKU、名称和关键规格找到。
- 带“区分”标记的规格是否完整，是否出现重复商品。
- 主库存单位是否符合日常盘点和成本核算习惯。
- 采购、销售使用的包装单位是否有明确、受控、可复算的换算。
- 商品是否应用了正确的系列包装模板，特例是否确有必要。
- 仓库是否代表真实存放和责任范围，收货地址是否可直接使用。
- 停用资料是否仍能在历史单据和库存流水中查询。

## 十、常见问题

### 为什么采购可以按吨报价，库存却按千克显示？

采购计价单位和主库存单位可以不同，但必须通过受控换算得到可复算的主数量。这样既符合供应商报价习惯，又能保证库存、成本和盘点口径一致。

### 一盘铜管的重量每次都不同，能否设固定换算？

不应为了省步骤填写估算固定值。应按实际业务支持的称重或实际换算方式记录，并让单据和库存批次保存当时结果。

### 同一个商品有多个供应商，是否要建多个商品？

通常不需要。商品身份由实际货物和关键规格决定；供应商编码、价格和供货包装属于供货关系。只有货物规格或库存管理要求确实不同，才建立不同商品。

### 资料填错后能否直接改？

尚未形成业务事实、且不改变商品身份含义的资料可以更正。已经进入订单、出入库或库存的关键规格、单位和换算，不应直接改写历史；应保留原资料并通过业务变更、撤销、冲正或新建正确商品处理。

### 为什么看不到新增或编辑按钮？

系统按岗位权限显示操作。请让管理员核对当前用户是否具有对应的商品、仓库或高级主数据维护权限。不要借用他人账号操作。

## 十一、完成标准

基础资料准备完成，不是指页面里“有几条数据”，而是能用真实业务验证：

1. 从不同形态商品中各选一项完成采购下单和入库。
2. 能按真实仓库、主库存单位和批次查到结存。
3. 使用常用销售或包装单位完成销售下单和出库，换算结果可复算。
4. 商品、订单、出入库、库存流水中的名称、规格、单位和来源保持一致。
5. 停用资料不再进入新业务，但历史记录仍然完整可查。

验证通过后，再逐步扩大商品范围和批量导入规模。
