# Copper ERP 使用手册

本目录保存 Copper ERP 面向最终用户的使用手册，并作为系统内“帮助”页面的内容来源。

## 已有手册

- [基础资料使用手册](./BASE_DATA_USER_GUIDE.md)

## 编写约定

- 按用户在系统中看到的菜单、按钮和状态名称编写，不使用接口名或数据库字段名。
- 先说明适用角色、准备条件和推荐顺序，再说明具体操作。
- 明确哪些操作会影响后续业务、哪些历史资料不能直接删除，以及发生错误时如何恢复。
- 页面入口、业务规则或权限发生变化时，应在同一变更中同步更新对应手册。
- 新模块手册使用独立的 Markdown 文件，并在本文件和前端帮助中心的手册清单中登记。
