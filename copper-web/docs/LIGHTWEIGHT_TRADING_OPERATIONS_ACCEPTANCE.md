# 轻量商贸经营能力内部验收

> 验收日期：2026-07-24
>
> 状态：`COMPLETED_INTERNAL_ACCEPTANCE`
>
> 适用范围：面向小微铜材经销商的轻量经营能力包；不代表正式发布、客户交付或第三方平台直连已经完成

## 1. 验收范围

本次只补经销商高频经营事实和可选助手，不建立大型企业流程：

1. 送样、内部领用、正常损耗和其他出入库形成真实库存流水、成本过账和可追溯冲正。
2. 按近 30 天出库、供应交期、安全覆盖期、自由库存和在途采购给出透明补货建议，并展示最老库龄；建议不自动下单。
3. 销售额、库存成本、已归集费用、毛利、贡献毛利和未收款保持分项可追溯，老板首页只显示必要汇总。
4. 手机窄屏可使用经营助手；出库页支持 HID 键盘模式扫码枪或蓝牙扫码枪辅助匹配最早可用批次，仍由人员确认发货。
5. 质保书按库存批次登记、复核、驳回或作废，不把不适用商品强制纳入质量流程。
6. 销售出库旁记录自提、自送或物流的发出、签收和异常事件；签收不等于收款或核销。
7. 采购草稿旁可登记和选择供应商报价；选择结果不会静默修改采购订单价格、税额或单位换算。
8. 复用现有银行、发票、电子凭证和期初数据文件导入；新增按单据到期撤销的只读分享及按往来单位隔离的最小读取密钥，不虚构银行、税务或物流平台直连。

- Web：`pnpm test:production`，121 项通过；`pnpm build` 通过。
- Backend：`mvn -q test`，265 项通过。
- 隔离 MySQL 8.4：`tests/run-lightweight-trading-operations-local-database.sh` 从空库执行全部迁移，并完成送样冲正、补货建议、报价选择、销售费用归集与撤销、交付签收、质保复核、只读分享及按往来单位隔离的读取密钥验收。
- 实库场景结束后随机数据库、临时账号、文件目录和测试业务事实均自动清理；事务失败场景确认不遗留半成品。
- 实库脚本在执行前强制清理 Maven 构建目录，避免其他分支遗留迁移文件污染 Flyway 版本判断。

在全新隔离 MySQL、Backend `8193` 和临时 Web `18080` 上完成：

- 全新系统从空库迁移后正常启动并通过 readiness。
- 管理员首次登录、改密和权限菜单正常，正式 `8191` 服务未被替换或停止。
- 1280px 桌面端经营助手的六张老板摘要卡、补货库龄、销售贡献、导入协同和最小密钥区均可访问，无横向裁切。
- 390×844 手机窄屏下摘要卡单列显示，经营助手本体无横向溢出；销售贡献与导入协同页签可切换。
- 新建出库页显示扫码拣货入口，在未选择仓库时保持禁用，不会绕过仓库、批次和人工确认。
- 无效、过期或已撤销的公开分享链接使用无后台框架的独立页面并统一提示不可访问，不泄露单据存在性或内部信息。

浏览器验收过程中发现并修正了经营助手单列网格被宽表最小内容撑开的裁切问题；修复后桌面端网格宽度与内容区一致，手机端页面宽度与视口一致。

## 4. 不得扩大的结论

- 以上能力均为可选助手或原业务单据旁的附加动作，不是采购、销售、发货、收付款或关账的前置条件。
- 补货建议、报价选择、扫码匹配和经营汇总均不能替代人工确认、库存事实、资金流水、核销关系、税票或会计凭证。
- 只读分享和读取密钥只解决最小外部查询，不是客户门户、开放平台、电子数据交换、运输管理或第三方平台双向集成。
- 本记录只证明当前内部能力包及受影响合同已通过相称验收；正式发布、客户部署、第三方联调和法定税务处理仍需独立验收。
