## 2. 数量合同修复

- 与后端 V49 的 `decimal(24,6)` 数量事实对齐，通用数量展示最多六位、去掉末尾零；金额仍保留原有两位口径，单价和税率沿用各自字段定义。
- 采购、销售、报价、入出库、退货、调拨、盘点、直运发出/实收/退货、采购跟催、发票数量、采购费用分摊重量及商品包装/供货条款均允许六位数量。包装整件限制和商品规格字段的独立精度继续由原规则控制。
- 逐包装合计、来源包装扣取及库存余量差异使用六位定点单位核对，避免二进制浮点加总误差，差一百万分之一也不能被两位舍入掩盖。提交数据继续由服务器复算、校验和过账。
- 手工逐包录入、批量粘贴和标签识别不再截成两位；旧草稿中的六位数量打开后不会被两位控件截断。
- 标签识别返回 kg，套用前明确换算为 kg/千克/公斤、t/吨或 g/克；未知及非重量主库存单位拒绝自动套用，保留人工按受控单位录入路径，避免把 kg 静默当成 t 或件。
- 此修复不变更库存、应收应付、资金或会计的过账时点，不重算历史业务，不添加数据库迁移。
