> 状态：`COMPLETED_CURRENT_INTERNAL_WEB_BASELINE`

> 日期：2026-07-24

> 范围：手机登录自动分流、统一手机工作台、查货、报价/下单草稿、收款、扫码盘点草稿、拍照归单和静态 PWA 壳层

## 1. 产品边界

- 只建设一个权限驱动的手机工作台，不建设老板、销售、仓库、财务多套 App，也不提供角色切换。
- 手机与电脑版复用相同登录、权限、数据范围、API、状态机和审计记录。
- 手机浏览器登录成功后默认进入 `/mobile`；电脑保持原工作台入口，已明确指定的手机子页面返回目标予以保留，强制修改初始密码始终优先。
- 查货只读；报价和销售订单只保存草稿；盘点只保存待复核草稿；收款与附件必须在线提交。
- PWA 只缓存静态应用壳层，所有 `/api/` 请求保持网络直连，不支持离线记账、离线过账或恢复网络后自动补写。

## 4. 业务安全断言

- 快速报价和订单保存前后不改变库存、应收、收付款、发票、凭证和总账。
- 扫码盘点保存前后不改变库存；正式盘盈盘亏只能在原盘点详情确认后形成。
- 回款仍区分到账与核销，允许一笔资金分配多单和暂不分配，银行收款仍要求实际账户。
- 拍照只新增原业务单附件和审计信息，不触发采购、入库、交付、应收应付、收付款或会计过账。
- 断网或主机不可达时，所有写操作入口停止提交；没有成功提示时必须先查原业务记录。
- 手机未提交草稿按登录用户隔离；主动退出或登录失效时清除，不能跨用户恢复或冒充正式业务。

## 5. 结论边界

本验收只证明当前内部 Web 基线的手机快速办事能力；手机默认进入统一工作台，强制修改初始密码仍优先。不证明正式客户设备、相机兼容矩阵、互联网远程访问、公开发布、应用商店交付或离线业务能力已经完成。
