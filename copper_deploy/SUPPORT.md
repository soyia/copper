# Copper 工程候选支持与版本生命周期

生效范围：2026-10-16 工程候选交付，见 [本次范围决定](docs/RELEASE_SCOPE_20261016.md)。本文件记录现有可履行的支持边界，不表示已有稳定版、已签服务合同或律师批准。

## 问题入口

有仓库访问权限的操作者通过对应 GitHub 仓库 Issue 提交普通缺陷；应提供候选编号、三仓提交、合成复现步骤和脱敏错误标识。受限仓库访问不等于已经开放公共支持渠道。不得上传客户数据、备份、密钥、完整 Cookie、银行账号或未脱敏日志。

疑似漏洞使用 [SECURITY.md](SECURITY.md) 的私密报告入口。普通 Issue 不承载漏洞利用细节。一般需求和服务响应时间以真实签署的服务范围为准；未签署时不承诺值守、上门、7×24 或固定恢复时限。

## 版本与升级

- 当前新候选为 `0.4.0-rc.7`，只有冻结和实际验证的组件组合可用于对应验收。分支 HEAD、未提交工作区和工程包版本不冒充已安装产品版本。
- 候选使用者应核对同版本发布说明、已知问题、验证状态、备份与回退合同。来源版本未列入目标升级矩阵时，默认不支持直接升级。
- 后续稳定版维护范围与终止日期随真实发布说明明确；当前没有可据此推定的稳定版维护承诺。计划性稳定节奏仍按既定版本政策，安全或账实正确性修复可按风险紧急发布。
- schema/data 已变化时，不得仅切回旧镜像或运行未经验证的逆向 SQL。使用已验证整站备份或保留旁路旧站恢复。
- 升级必须由站点拥有者决定并选择维护窗口，先验证备份与恢复证据。停止付费或停止人工维护不能导致已有部署核心业务或数据被锁定。

## 支持范围与退出

本轮工程验收不改变首发拟支持的 Ubuntu Server 24.04 LTS x86_64 客户云范围。本地/LAN/NAS、ARM、Windows VM、Cloudflare 远程入口、扫码枪和针式打印继续按原范围延期；未执行的容器、浏览器、手机和实体设备验收必须分别标明。

客户或测试站点拥有者保管账号、域名、服务器和备份恢复资料。终止维护时，应交回对方控制的账号、已授权源码/版本清单、备份和运维记录，撤销临时访问，并明确仍需保留的审计记录；不得以结束支持为由删除业务事实或远程禁用站点。真实客户私钥交接、见证、最终许可和商业签署在本次交付中按负责人决定延期，不得填写虚假的完成记录。
