## 3. 验收步骤

### A. 证明是受支持空白机

- [x] 云镜像为原始 Ubuntu Server 24.04 LTS x86_64，不复用 `local-database` 或生产主机。
- [x] 仅放行 SSH 管理来源和公网 80/443；未放行 8191、3306 或其他 Copper 内部端口。
- [x] 从受控中转机生成并校验 Docker 离线 DEB；使用发布包内 `scripts/install-offline-ubuntu.sh` 安装 Docker Engine 29.x 与 Compose Plugin 5.x。
- [x] `sudo ./scripts/m1-07-preflight.sh` 无失败项，并保存脱敏输出。

### B. 只使用发布包安装

- [x] 校验 `SHA256SUMS` 后解压发布包；未克隆前端/后端源码。

- [x] 私有 GHCR 凭据只存在于中转机；导出三个 `linux/amd64` 不可变镜像后立即 `docker logout ghcr.io`。
