# M4-07 完全断网与空白 x86_64 最终验收

> 跟踪任务：<https://github.com/soyia/copper_web/issues/33>
>
> 本文是可重复执行的验收规程；实际结果必须写入独立脱敏报告。不得把候选包、开发分支或单次容器启动冒充正式发布。

## 1. 验收目标

在清除了既有 Copper 容器、网络、数据目录和发布 READY 的 Ubuntu Server 24.04 amd64 主机上，证明：

1. 只使用正式发布清单、部署归档、离线镜像介质和产品命令完成安装，不修改源码，不手工执行写 SQL。
2. 客户域名通过真实公开 CA 证书提供 HTTPS；Backend 8191 和 MySQL 3306 不映射宿主机。
3. 阻断 Copper 运行容器主动访问公共互联网后，登录、采购、入库、库存、销售、出库、收付款和查询仍完整运行。
4. 证书续期、客户 S3、客户 Webhook 和联网交付是条件能力；不可用时明确降级但不阻塞无关核心业务。
5. 客户可以独立查看备份、磁盘、证书、时间、健康和处置清单；不存在远程许可证心跳、强制遥测或远程停用开关。
6. 同一候选镜像重新通过 M4-06 故障恢复与经营财务不变量复验。

## 2. 正式介质门槛

- `copper-release/v1` 发布清单必须通过严格校验，并绑定 Web、Backend、MySQL 的不可变摘要、源码提交、schema、迁移集合、备份和导出格式。
- `copper-delivery/v1` 离线索引必须通过独立 SHA-256 交接；介质只包含索引声明的部署包、清单、升级矩阵、发布说明、ACME 归档和三张 amd64 镜像。
- 无 GHCR Token 的发布工厂可以使用 GitHub Actions 工件，但必须同时验证 CI 证据、源码提交、工作流、发布摘要、归档 SHA-256、OCI manifest 和本地镜像 ID。
- 验收候选从已经合入 GitHub `main` 的 Deploy 提交生成；正式标签与 Release 只能在全部验收通过后创建。

## 3. 空白边界

“空白主机”是指保留受支持操作系统、Docker Engine/Compose 和验收所需基础工具，但不存在 Copper 容器、网络、卷、数据目录、秘密、发布 READY 或监听端口。复用验收服务器时必须先完成这一清理并保存清理前后清单；禁止覆盖任何客户站点。

宿主机仅允许 80/443 作为产品入口。SSH 属于客户基础设施管理面，不属于 Copper 产品端口；安全组和访问控制由客户管理。8191 必须始终未占用。

## 4. 执行顺序

1. 在可信发布工厂从 GitHub `main` 构建 `0.3.0-rc.3` 候选发布目录和安全证据。
2. 使用经过 CI 绑定验证的 Web、Backend 工件及固定 MySQL 镜像生成正式离线交付目录。
3. 将离线目录和独立索引 SHA-256 通过不同渠道交付到验收机。
4. 确认 DNS 指向验收机、80/443 可达、8191 未占用，运行：

   ```bash
   sudo COPPER_M4_FINAL_KEEP_RUNNING=1 \
     tests/run-m4-final-x86-acceptance.sh \
     /path/to/copper-delivery-offline-0.3.0-rc.3.json \
     <INDEX_SHA256> \
     <CUSTOMER_DOMAIN>
   ```

5. 脚本从正式归档安装、取得真实证书、验证 Cookie、一次性管理员凭据使用即销毁，随后只阻断 Copper 容器的新建公网连接；已建立的客户 HTTPS 响应保持可用。
6. 在断网门槛生效时，脚本只经正式 HTTPS API 完成采购到收付款闭环并创建、验证客户公钥加密备份；不执行写 SQL。
7. 从独立客户浏览器检查公开证书链、登录、工作区、关键查询和安全响应头；浏览器不得使用跳过证书验证选项。安全响应头至少包括 CSP、HSTS、`nosniff`、同源防嵌入、同源来源策略和禁用摄像头/定位/麦克风权限策略，并由最终验收脚本逐项断言。
8. 恢复容器外联并停止公开站点后，使用同一离线 READY 的三张本地镜像运行 M4-06 完整故障复验。
9. 将两组证据制成 root-only SHA-256 清单，报告只记录版本、提交、摘要、耗时和结论，不记录 IP、SSH 密钥、密码或客户数据。

## 5. 外联和第三方说明

客户运行 `sudo copperctl security egress status --json` 可查看当前合同。核心运行时没有 Copper 官方地址：

- 许可证心跳：关闭。
- 强制遥测：关闭。
- 远程停用开关：关闭。
- Copper 官方服务端点：空集合。

条件外联仅包括：公开 ACME 证书服务、客户主动配置的 S3、客户主动配置的 Webhook，以及管理员主动选择的联网交付地址。状态命令只显示目标类别和用途，不读取通知密钥、对象存储密钥或业务明细。

## 6. 完成与清理

最终报告至少记录：正式介质 SHA-256、三张镜像的发布摘要/本地 ID、TLS 颁发者和有效期、Cookie 门槛、断网防火墙命中、业务闭环、备份/恢复密钥证明、第三方降级、客户自助状态、M4-06 复验、schema/表数、结构风险和总耗时。

浏览器验收后必须撤销测试防火墙规则、停止站点并使用产品危险删除流程清理测试数据。最终只保留 root-only 脱敏证据；8191、3306 不得出现宿主机监听。
