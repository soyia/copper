## 样本结论与度量

- 工程链结论：`INTERNAL_REHEARSAL_FLOW_PASSED`。空白预检、安装、首次凭据、权限、主数据、备份、离线解密、旁路恢复、自由导出、监控和自动备份均有真实证据。
- 自助结论：`SUPPORT_REQUIRED`，不得宣称“零研发干预”。修正文档和产品缺陷后仍需新的独立操作者样本，才可形成零干预结论。
- 安装开始至三层健康：28 分 40 秒。
- 一致性备份：约 22 秒，51,200 bytes，服务自动恢复健康。
- 旁路恢复状态记录：45 秒达到 `VALIDATED`；不切换正式数据。
- 完整导出：约 1 秒生成，75,273 bytes，88 张业务表、1,256 条记录、93 个 UTF-8 CSV。
- 可复核的额外支持窗口约 15 分钟；首份样本还混有自动等待和问题记录时间，因此只用于建立基线，不用于冻结正式服务工时或价格。

## 必须修正的支持事件

1. 离线介质把 OCI config digest 表述为 Docker 可运行本地 ID，Docker 29.6.2 导入后按该值查询失败。
2. 首次配置缺少从 READY/离线镜像证据安全填写非秘密字段的完整手册步骤。
3. 离线验证说明遗漏必须同名传输 `.sha256` 侧车，且未强调备份主文件不得改名。
4. 客户云没有可挂载安全介质时，手册缺少“SSH 标准输入 -> `/run` tmpfs -> 恢复结束强制销毁”的受控私钥使用流程。
5. 备份输出固定声称发布到本地、NAS 和 S3，但实际只配置 `targets=[local]`，文案与事实不一致。
6. 铜排 `HTCJ25-3` 预设只提供组合“尺寸”，未映射系列必填的独立宽度和厚度，操作者被迫手填。
