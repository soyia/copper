## 4. 失败关闭证据

演练没有绕过失败门槛：

1. 域名带测试端口时，备份配置校验拒绝继续。
2. `offline` 模式使用可变本地镜像标签时，发布配置校验拒绝继续；改为精确 `sha256` ID 后才通过。
3. 临时 Compose 端口覆盖不能被备份重启链继承，80/443 冲突时服务恢复失败；改用产品内置 `external-proxy` 模式后，备份停写、三层恢复和 `BACKUP_RECOVERED` 留痕通过。

原首次改密已经正常通过。自动化脚本随后丢失仅驻留内存的新密码，为继续处理一次性测试站点，使用与源码一致的 PBKDF2 参数重置了测试管理员密码；这不是产品客户恢复流程，不得作为正式运维说明。
